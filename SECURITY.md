# Security policy

Use this fork's
[private vulnerability report form](https://github.com/zhangtyzzz/grok-build/security/advisories/new)
for suspected vulnerabilities in its code, installers, or published builds.
Include the affected version, platform, reproduction steps, and impact.
Redact credentials and personal data. Keep vulnerability details out of
public GitHub issues.

For vulnerabilities in the upstream project, follow
[SpaceXAI's security policy](https://github.com/xai-org/grok-build/blob/main/SECURITY.md),
which directs reports to [HackerOne](https://hackerone.com/x).
